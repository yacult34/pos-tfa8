# Pastel POS Laravel Application

A pastel-themed point-of-sale application built with Laravel.

## Features

- Laravel Breeze authentication
- User registration and login
- Protected customer management pages
- Protected user account management pages
- Customer CRUD operations
- User account CRUD operations
- Resource controllers
- Resource routes
- SQLite database
- Responsive pastel user interface

## Requirements

- PHP 8.2 or higher
- Composer
- Node.js and npm
- Git
